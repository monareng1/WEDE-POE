## Overview
A responsive, multi-page web application for Buffalo's BnB located in Greenpark, Boksburg.

## Part 1 Development Overview
* **Wireframe & Site Planning:** Created structural wireframes establishing the 6 core pages (Home, About Us, Amenities, Rates & Policies, Gallery, Contact Us).
* **Initial Page Setup:** Built semantic HTML structures for all primary website sections.
* **Branding & Assets:** Implemented custom branding assets including the Buffalo's BnB logo, layout backgrounds, and local property photos.
* **Core Content:** Documented founding details (established by Ray & Elizabeth Monareng in 2021) and key estate features inside Greenpark Eco-Estate.

---

## Part 2 Changelog & Iteration
* **CSS Architecture:** Refactored inline/internal styling into a unified master `style.css` stylesheet for global consistency[cite: 8].
* **Layout Structure:** Implemented standard `.container`, `.grid-2`, and `.home-card` structures across all pages[cite: 8].
* **Navigation:** Standardized links across all 6 pages to include the dedicated "Contact Us" page[cite: 8].
* **Gallery Enhancement:** Applied fixed-aspect-ratio containers (`object-fit: cover`) and pop-out hover effects with visible captions for all 6 gallery categories (Kitchen, Balcony, Pool, Chilling Area, Bedroom, Living Room)[cite: 8].
* **About Page Interactive Feature:** Implemented a hover-to-expand transition on the historical overview section[cite: 8].
* **Amenities Page Updates:** Integrated local area highlights including proximity to O.R. Tambo Airport and East Rand Mall[cite: 8].
* **Contact Us Page:** Added host phone numbers (+27 82 123 4567), email placeholders, and a direct booking inquiry form[cite: 8].
